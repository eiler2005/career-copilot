# PDF-документы и сборники для чтения

[English](../PDF.md) · [Русский](PDF.md) · [Документация](../../README.ru.md#документация)

Единый локальный PDF-конвейер обслуживает учебные планы, заметки подготовки, вёрстку CV и сборники для чтения. Он строит PDF из Markdown, проверяет файлы, собирает документы в заданном порядке на листах A4 и извлекает выбранные страницы. Исходники и постоянные результаты находятся внутри явно выбранного приватного пространства.

Каждый пользовательский PDF по умолчанию должен использовать основной шрифт 12 pt и текст таблиц не меньше 11 pt: это относится к учебным планам, CV, выгрузкам dashboard и сборникам. В воспроизводимых командах явно указывайте `--font-size 12`. Пользователь может запросить другой размер, но одно лишь число страниц не является причиной уменьшать читаемый текст. Python API сохраняет прежний размер 9,5 pt, если `render_markdown()` вызван без `font_size`, поэтому существующая вёрстка CV и dashboard не меняется; для новых пользовательских вызовов передавайте `font_size=12`, а стили таблиц должны оставаться не меньше 11 pt. При размере по умолчанию заголовки остаются крупнее.

Для выдаваемого сборника сохраняйте геометрию исходных страниц и размер текста 100%: используйте `pdf bind ... --preserve-size`. Подгонка под A4 доступна для совместимости и промежуточной работы, но не является режимом выдачи пользовательского сборника. Подпись ставится в нижнем поле 4 мм, поэтому перед выдачей проверьте, что оно свободно. Размер шрифта и режим геометрии записываются в манифест.

## Сверстать план

Пути ниже — примеры; сначала создайте исходник в своём пространстве. Глобальный `--home` стоит перед командой; входы можно задавать относительно пространства, выходы задаются относительно него.

```sh
uv run ajh --home /absolute/private/career-workspace pdf render learning/plan.md \
  --output learning/pdf/plan-v1.pdf \
  --font-size 12 \
  --title "План подготовки" --subtitle "Изучение, практика и разбор"
uv run ajh --home /absolute/private/career-workspace pdf inspect learning/pdf/plan-v1.pdf
uv run ajh --home /absolute/private/career-workspace verify
```

Добавьте `--landscape`, если исходнику нужно больше места по горизонтали. Смена ориентации — решение вёрстки, а не повод сокращать содержание. Для новой редакции исходника или других параметров выбирайте новое имя PDF.

Рендерер поддерживает заголовки, абзацы, выделение, нумерованные и ненумерованные списки, вложенные списки, цитаты, блоки кода, таблицы, ссылки и отдельные локальные PNG/JPEG-иллюстрации. Заголовок таблицы повторяется при переносе на следующую страницу; картинки внутри ячеек не поддерживаются. Маркер `<!-- pagebreak -->` между разделами задаёт явный разрыв страницы. HTTP(S) и почтовые ссылки могут быть кликабельными, но их содержимое не загружается. У локальных ссылок печатается подпись без активного адреса. Путь к картинке считается от Markdown-файла и должен оставаться внутри приватного пространства, в том числе после разрешения символических ссылок. CLI встраивает эти локальные иллюстрации; PDF планов из dashboard сохраняет только подписи картинок, не читая сами файлы изображений.

Это рендерер Markdown-документов: HTML печатается буквально; произвольная HTML/CSS-вёрстка, скрипты и загрузка удалённых картинок не поддерживаются. Проверяйте читаемость таблиц; слишком широкую таблицу перестройте или используйте альбомную ориентацию. Блок кода печатается как текст и никогда не выполняется. Нужны Python-зависимости проекта (ReportLab, pypdf и markdown-it-py) и Unicode TTF; `uv sync --all-groups` устанавливает Python-зависимости. В Docker-образ включены шрифты DejaVu.

## Собрать и извлечь

`bind` принимает PDF в указанном порядке, вписывает страницы в A4 и добавляет нумерацию и закладки документов. Сначала сверстайте Markdown, затем объедините результаты:

```sh
uv run ajh --home /absolute/private/career-workspace pdf bind \
  learning/pdf/plan-v1.pdf learning/pdf/practice-v1.pdf \
  --output learning/pdf/reading-pack-v1.pdf --title "Материалы подготовки" \
  --preserve-size
uv run ajh --home /absolute/private/career-workspace pdf extract \
  learning/pdf/reading-pack-v1.pdf --pages 1 3 \
  --output learning/pdf/selected-pages-v1.pdf
```

Пример извлекает страницы 1 и 3, а не диапазон. После сборки или извлечения осмотрите итоговый файл: его номера и геометрия страниц могут отличаться от входных. Сохраняйте отдельные PDF и Markdown рядом со сборником, чтобы новую редакцию можно было собрать из исходников.

## Артефакты и повторяемость

Команды создания регистрируют PDF и соседний `OUTPUT.pdf.manifest.json` через хранилище артефактов пространства. Манифест содержит хеши входов, хеши ресурсов, если они использованы, и метаданные результата. Каждый экспорт также регистрирует неизменяемую запись `pdf_documents` и событие `pdf_exported`. Запись связывает манифест и результат; её ID — `pdf-` и первые 20 символов SHA-256 манифеста. Идентичный повтор использует те же артефакты и запись документа; попытка записать другие байты по занятому пути отклоняется. Не редактируйте зарегистрированный файл вручную: выбирайте новый путь и сохраняйте прежнюю версию.

`pdf inspect` показывает число страниц, SHA-256 и размер PDF в байтах без перезаписи. `verify` проверяет целостность зарегистрированных артефактов. Ни одна команда не проверяет достоверность, читаемость или учебный прогресс. Универсальные PDF-команды не создают CV-пакет, модельное авторство, положительное ревью или результат практики. Для внешних документов действуют [правила авторства и ревью пакета](CV_PROFILES.md).

CLI — механический компилятор. Сложное планирование, архитектура и содержательные решения принадлежат флагману среды (`gpt-6-astra` в Codex/OpenAI, `claude-opus-5` в Claude); простое исследование и извлечение может выполнять более экономичная модель, например `gpt-5.6-luna`. Независимое содержательное ревью выполняется отдельной сессией флагмана, отличной от всех авторов/редакторов. Записывайте фактических исполнителей: сборка не означает модельное авторство. Подробнее — [рабочий цикл](WORKFLOW.md).

## Осмотреть страницы

Извлеките текст и проверьте окончание, заголовки, ссылки и кириллицу. Затем отрисуйте каждую страницу через Poppler и просмотрите изображения в читаемом масштабе:

```sh
pdftotext /absolute/private/career-workspace/learning/pdf/plan-v1.pdf \
  /absolute/private/career-workspace/learning/pdf/plan-v1.txt
pdftoppm -png -r 120 /absolute/private/career-workspace/learning/pdf/plan-v1.pdf \
  /absolute/private/career-workspace/learning/pdf/plan-v1-page
```

Проверьте поля, пропорции картинок, строки таблиц и повтор заголовков, отступы списков, разрывы, типографику и последнюю страницу. Обрезанный, налезающий или нечитаемый текст требует исправления исходника или рендерера и новой версии артефакта. Положительное визуальное ревью фиксируется только после осмотра точных выдаваемых байтов: успешная сборка и тесты его не заменяют.

Превью, извлечённый текст и манифесты тоже содержат приватные сведения. Храните их вне публичного checkout и следуйте [правилам приватности](PRIVACY.md). Владение модулями описано в [архитектуре](ARCHITECTURE.md#общий-слой-pdf), команды — в [справочнике CLI](CLI.md).
