# Job Search Agent

Локальный помощник для поиска работы, подготовки доказательных CV и интервью.
Два карьерных трека — `product` и `technical-leadership` — используют одну
приватную базу фактов. SQLite хранит рабочий журнал; исходные наблюдения,
документы и ревью сохраняются с версиями и хешами. HTML-обзор строится из журнала.

## Установка и синтетический пример

Поддерживаются macOS и Linux. Нужны Python 3.12+, `uv` и Unicode TTF-шрифт для PDF. На Linux подходит DejaVu
Sans; другой путь указывается в приватном `settings.json` в поле `pdf_font`.
Из корня этого репозитория:

```sh
uv sync --all-groups
uv run ajh --help
uv run ajh --home /tmp/job-search-demo-EXAMPLE init --demo
uv run ajh --home /tmp/job-search-demo-EXAMPLE demo
uv run ajh --home /tmp/job-search-demo-EXAMPLE evaluate --track product
uv run ajh --home /tmp/job-search-demo-EXAMPLE prepare master --track product
uv run ajh --home /tmp/job-search-demo-EXAMPLE prepare master --track technical-leadership
uv run ajh --home /tmp/job-search-demo-EXAMPLE learn --track product
uv run ajh --home /tmp/job-search-demo-EXAMPLE learn --track technical-leadership
uv run ajh --home /tmp/job-search-demo-EXAMPLE report --open
uv run ajh --home /tmp/job-search-demo-EXAMPLE verify
```

Обзор находится в `/tmp/job-search-demo-EXAMPLE/report/index.html`; исходники и
PDF — в `packages/` того же демонстрационного пространства. Публичные инструкции
находятся в `README.md` и `docs/`, а код локального интерфейса —
в [report.py](src/job_search_agent/report.py). Отдельная frontend-сборка не нужна.

`init --demo` требует новый или пустой каталог; `demo` заполняет его вымышленными данными. Для
собственных данных используйте `init` и отдельный абсолютный путь вне исходников.
`--home` ставится **перед командой**. Временный каталог годится для демонстрации;
для реальной работы выберите постоянное приватное хранилище и резервирование.

`prepare` без `--cv` создаёт механический черновик и задание агенту. Это позволяет
пройти цикл без модельного API, но такой документ остаётся `pending`. Авторство
и независимое содержательное ревью выполняет Opus в Claude или Astra в Codex.
Автоматического вызова модели, отправки отклика и переписки в CLI нет.

## Границы первой версии

CLI выполняет сбор через поддержанные API и JSON-LD, повторный анализ снимка,
оценку явных доказательств, сборку Markdown/PDF/текста, регистрацию ревью,
планирование обучения и локальный отчёт. Семантическое сопоставление опыта,
проверка уровня работодателя, авторство, просмотр страниц и подтверждение
прогресса требуют работы агента или пользователя. Браузерный и поисковый доступ
— ручные резервные маршруты; встроенного фонового планировщика нет.

Состояния соответствия вакансии, готовности документов, обучения и отправки
независимы. Успешный технический `verify` не заменяет содержательное ревью.
Публикация репозитория и внешнее зашифрованное резервирование требуют отдельно
настроенных назначений; наличие локальных файлов не означает выполнение этих шагов.

Проверки разработки: `uv run ruff check .`, `uv run ruff format --check .`,
`uv run pytest`. Перед передачей изменений также выполните проверки приватности
из [PRIVACY.md](docs/PRIVACY.md).
