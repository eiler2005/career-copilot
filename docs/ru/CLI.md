# Справочник CLI

[English](../CLI.md) · [Русский](CLI.md) · [Документация](../../README.ru.md#документация)

Запускайте `uv run ajh` из публичного checkout. Глобальные параметры предшествуют команде:

```sh
uv run ajh --home /absolute/private/career-workspace --activity-id ACTIVITY_ID evaluate VACANCY_ID --track product
```

Вне выполняющегося задания навыка `--activity-id` не нужен. Пространство также задаётся через `AI_JOB_HUNTER_HOME`. Команды выводят JSON; `report --open` дополнительно открывает локальный файл.

Отдельная команда `uv run ajh-dashboard --home ABSOLUTE_WORKSPACE [--host 127.0.0.1] [--port 8080] [--allowed-host HOSTNAME] [--state-dir PATH]` запускает приватный веб-сервер только для чтения в открытом терминале. `--state-dir` (вне пространства) включает проверки доступности из интерфейса. Повторяйте `--allowed-host` (или задайте через запятую `AJH_DASHBOARD_ALLOWED_HOSTS`) только для имени хоста, которое обслуживает прокси с авторизацией. Параметр пространства принадлежит этой команде; запуск не создаёт activity и не изменяет записи журнала. Подробнее — [веб-интерфейс и размещение](DASHBOARD.md).

## Команды и результаты

| Команда | Вход/параметры | Результат |
| --- | --- | --- |
| `init [--demo]` | Новое/пустое внешнее пространство | Маркер, настройки, пустые факты |
| `demo` | Только синтетическое пространство | Вымышленные факты, компания, вакансия |
| `facts import PATH` | JSON и реальные локальные файлы/URL источников | Версии фактов и копии доказательств |
| `record companies PATH` | Полная карточка компании | Замена целиком и событие до/после |
| `record vacancies PATH` | Полная карточка вакансии | Замена целиком и событие до/после |
| `discover` | Необязательный `--source ID` | Снимки, наблюдения, статусы источников |
| `discover --source ID --replay PATH` | Совместимый снимок относительно пространства | Историческое наблюдение без сети и обновления live-статуса |
| `evaluate [ID] --track TRACK` | Вакансия необязательна; default product | Оценки правил по доказательствам |
| `prepare ID --track TRACK` | Вакансия или `master`; трек обязателен | Версионный пакет и задание агенту |
| `review PACKAGE_ID --report PATH` | JSON проверки точной версии | Ревью и пересчёт готовности |
| `learn [ID] --track TRACK` | Вакансия необязательна; default product | Базовый план или план по требованиям |
| `report [--open]` | Текущий журнал | Приватные HTML/JSON |
| `stats` | Текущий журнал | Детерминированные счётчики, отдельные состояния, доступная телеметрия |
| `verify` | Файлы и база | Целостность и число ожидающих ревью |
| `activity start --request PATH` | Запрос schema-v1 | Activity с ID, копиями входов и проверкой доступности модели |
| `activity show ID` | Существующая activity | Входы, целостность, события, возможность продолжения |
| `activity finish ID --result PATH` | Финальный результат schema-v1 | Неизменяемые результаты, артефакты, типизированные записи |
| `import-legacy PATH [--dry-run]` | Legacy registry schema-v2 | Проверенный перенос |
| `backup --destination PATH` | Новое назначение | Снимок базы/файлов и manifest |
| `restore SNAPSHOT --destination PATH` | Копия и новое назначение | Восстановленное пространство без активного `--home` |
| `privacy check` | `--scope`, `--root`, словарь, Gitleaks/artifact | Проверка публичного состава и приватности |
| `availability check [ID ...]` | `--unverified`, `--stale-days N`, `--limit N`, `--delay S` | Проверка сохранённых ссылок на объявления только на чтение; доступность, `availability_check`, история и событие |
| `availability import PATH` | Файл дашборда `availability-checks.json` | Переносит в журнал более свежие проверки из веб-интерфейса |
| `translations export --output PATH [--all]` | Текущий журнал | Тексты без русского или английского перевода |
| `translations import PATH` | Файл экспорта с переводами и фактической моделью переводчика `actor.model` | Записи `text_translations`; оригиналы не меняются |
| `maintenance dedupe [--apply]` | Текущий журнал | Оставляет самую новую оценку и план подготовки на вакансию и трек; остальные архивирует |
| `maintenance rename-artifacts [--apply]` | Текущий журнал | Переименовывает файлы с хеш-именами или слишком длинными именами в понятные; обновляет ссылки и пишет манифест |

`TRACK` — строго `product` или `technical-leadership`. Синтаксис доступен через `uv run ajh COMMAND --help`.

## Доступность, переводы и обслуживание

`availability check` читает только ссылки, уже сохранённые в вакансиях, проходит не больше пяти перенаправлений на публичные адреса и никогда не обходит вход, CAPTCHA или защиту от ботов. Без ID проверяются активные вакансии (не закрытые, не в архиве, не отклонённые). Каждый результат содержит `status` (`open`, `closed`, `unknown`), `reason`, `confidence`, видимый признак `evidence`, HTTP-статус, итоговый URL и время. Правила: HTTP 404/410 или явная видимая надпись «закрыта/в архиве» → закрыта (высокая уверенность); перенаправление, теряющее идентификатор объявления → закрыта (средняя); видимая кнопка отклика или опубликованная структурированная вакансия → открыта (средняя); блокировка доступа, ошибки или отсутствие надёжного признака → неизвестно. Записанное закрытое или архивное состояние не открывается сигналом средней уверенности — оно становится `conflicting` для решения человеком.

Команды `maintenance` работают как пробный прогон, пока не указан `--apply`. Сначала сделайте `backup`. `dedupe` переносит прежние результаты в `superseded_records` (с `superseded_by`) и выставляет указатели `current_assessments`/`current_learning`; старые ссылки продолжают открываться. `rename-artifacts` применяет схему имён из [модели данных](DATA_MODEL.md#имена-файлов-артефактов), перемещает файлы, переписывает ссылки в записях и `facts.json` и сохраняет манифест в `maintenance/`. Обе команды идемпотентны.

## Заявки из веб-интерфейса и задачи агента

| Команда | Результат |
| --- | --- |
| `inbox import PATH` | Копирует файлы заявок (каталог, один файл или JSON-массив) в `inbox_requests` со статусом `pending`; уже импортированные ID пропускаются, некорректные файлы подсчитываются |
| `inbox list [--status S]` | Показывает импортированные заявки |
| `inbox apply [--id ID]` | Применяет ожидающие заявки от старых к новым, каждую в своей транзакции с проверкой версии; итог `applied`, `queued_for_agent`, `conflict` или `failed` с причиной |
| `inbox reject ID --reason TEXT` | Отклоняет ожидающую заявку и сохраняет причину |
| `tasks list [--status S]` | Показывает задачи агента |
| `tasks next` | Возвращает самую старую задачу в очереди с шаблоном запроса activity (включая `related.task_id`) |

Повторное применение безопасно: обрабатываются только заявки `pending`. Конфликт оставляет запись без изменений; создайте новую заявку от текущего состояния. Задача переходит в `running`, когда `activity start` ссылается на неё, и закрывается только через `activity finish` этой activity. Типы заявок и поля описаны в [модели данных](DATA_MODEL.md#версии-записей-и-заявки).

## Авторские документы

Механический пакет позволяет осмотреть задание и остаётся pending:

```sh
uv run ajh --home /absolute/private/career-workspace prepare master --track product
```

После реального авторства флагмана:

```sh
uv run ajh --home /absolute/private/career-workspace prepare VACANCY_ID --track product \
  --cv /absolute/private/drafts/cv.md \
  --coverage /absolute/private/drafts/coverage.json \
  --author-model ACTUAL_FLAGSHIP_MODEL \
  --author-session ACTUAL_AUTHOR_SESSION
```

Подставьте фактические модель и сессию. `--letter PATH` добавляет запрошенное письмо. Покрытие — массив строк `{"fact_id":"ID","included":true,"reason":"Где раскрыт факт или почему исключён"}` для всех фактов контекста.

Для нескольких авторов/редакторов `--contributors PATH` принимает:

```json
{
  "schema_version": 1,
  "contributors": [{
    "role": "author",
    "environment": "openai",
    "model": "ACTUAL_FLAGSHIP_MODEL",
    "session": "ACTUAL_SESSION",
    "outputs": [{"document": "cv", "path": "cv.md", "sha256": "EXACT_SOURCE_HASH"}]
  }]
}
```

Роли — `author` и `editor`, документы — `cv` и `letter`. Путь абсолютный или относительно JSON. Совокупность вкладов должна подтверждать конечный хеш каждого включённого документа; промежуточные версии тоже можно сохранить. При отсутствии отдельных author-полей они берутся из первого участника. Явные author-поля должны быть корректны и совпадать с участником списка. Известные авторы/редакторы связанного CV и письма наследуются автоматически: новый список не стирает их вклад. Сессия независимого рецензента отличается от **всех** авторских/редакторских сессий.

Самостоятельное зарегистрированное письмо включается через `--letter-record RECORD_ID` вместе с `--cv`, без `--letter`. Проверяются хеш CV и актуальная версия, к которой привязано письмо. Изменение CV требует пересмотра и новой корректной привязки письма.

## Activity и статистика

JSON-контракты описаны в [работе агентов](AGENT_WORKFLOWS.md). Глобальный `--activity-id` связывает команды с activity. Перед продолжением проверяются хеши копий и исходных файлов.

`stats` считает данные SQLite и разделяет здоровье источников, доступность, оценку, готовность, свидетельства интервью и подтверждённые отправки. Неизвестные модель, токены и стоимость остаются неизвестными; их нельзя заменять нулём или догадкой. Длительность — календарное время между событиями, а не доказательство активной работы.

## Коды завершения и восстановление

Код 1 означает верхнеуровневый `passed: false`, код 2 — обработанную ошибку ввода/операции или синтаксиса, 0 — прочие результаты. Discovery возвращает список: отдельный источник может завершиться ошибкой при общем коде 0. Проверяйте каждый статус и охват.

`verify` может пройти с ожидающими ревью: смотрите также `pending_or_legacy_reviews`. Это не проверка истинности фактов, живой вакансии или разрешения отправки.

После прерывания откройте activity и проверьте пространство. Повтор finish с тем же результатом идемпотентен; другой финальный результат требует новой activity. Изменившиеся входы требуют новых хешей. После появления нужной модели заблокированная работа продолжается в связанной дочерней activity. Подробнее — [эксплуатация](OPERATIONS.md).
