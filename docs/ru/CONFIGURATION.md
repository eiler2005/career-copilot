# Настройки

[English](../CONFIGURATION.md) · [Русский](CONFIGURATION.md) · [Документация](../../README.ru.md#документация)

Настройки хранятся в приватном JSON рабочего пространства. CLI не выбирает каталог кандидата автоматически. Секреты остаются в переменных окружения, личные приоритеты — вне публичного checkout.

## Рабочее пространство и окружение

| Параметр | Назначение |
| --- | --- |
| Глобальный `--home ABSOLUTE_PATH` | Явное приватное пространство; ставится перед подкомандой |
| `AI_JOB_HUNTER_HOME` | Пространство по умолчанию, если нет `--home` |
| `AJH_PRIVACY_DICTIONARY` | Путь приватного словаря для проверок публикации |
| Git `ajh.privateDictionary` | Локальный резервный путь словаря |
| `proxy_env` источника | Имя переменной с URL разрешённого для источника прокси |

`--home` имеет приоритет над окружением. `privacy` и `restore` не требуют активного пространства. Поддержаны macOS и Linux: блокировка использует `fcntl`. Модельные возможности предоставляет отдельная сессия Codex/Claude.

## settings.json

Начальные настройки:

```json
{
  "sources": [],
  "policy": {
    "bigtech_company_ids": [],
    "company_levels": {},
    "russia_director_only": false,
    "market_effort": {}
  },
  "max_requests_per_run": 20,
  "weeks": 6,
  "hours_per_week": 6,
  "model_routing": {
    "openai": "gpt-6-astra",
    "claude": "claude-opus-5"
  }
}
```

| Поле | Значение по умолчанию и смысл |
| --- | --- |
| `sources` | Пусто: инициализация не включает сетевой сбор |
| `max_requests_per_run` | 20 запросов на запуск поиска |
| `weeks` / `hours_per_week` | 6 / 6 для базового учебного плана |
| `pdf_font` | Необязательный путь Unicode TTF; иначе проверяются стандартные DejaVu/Arial |
| `policy.bigtech_company_ids` | Пустой приватный список компаний с индивидуальными правилами уровня |
| `policy.company_levels` | Для компании: `accepted`, `below`, `source` |
| `policy.russia_director_only` | False; при true для остальных российских работодателей действует фильтр директорских названий |
| `policy.market_effort` | Ориентир планирования усилий; не квота результатов |
| `model_routing` | Идентификаторы флагманов; модели не запускаются, доступ к API не появляется |

Пример соответствия уровней с вымышленными обозначениями:

```json
{
  "example-systems": {
    "accepted": ["Example-Senior-Leadership"],
    "below": ["Example-Associate"],
    "source": "https://example.invalid/fictional-level-policy"
  }
}
```

Для реальной таблицы нужны проверенный источник, `level.raw` и `level.source` вакансии и содержательная оценка масштаба/семейства роли. Неизвестный уровень остаётся на уточнении. Название должности — эвристика, а не доказательство обязанностей.

## Поля источника

Адаптируйте отключённый [пример](../../examples/source-config.json) в приватном пространстве. Перенесите его `sources` в текущие настройки, сохранив остальные поля.

| Поле | Обязательность / default | Поведение |
| --- | --- | --- |
| `id`, `provider`, `company_id` | Обязательны | Идентичность источника/компании и парсер |
| `board` | Greenhouse, Lever, Ashby | Токен публичной доски |
| `employer_id` | HH | Фильтр работодателя |
| `url` | Corporate/manual | URL страницы или endpoint |
| `enabled` | True, если не задано | Участие в поиске |
| `company_name`, `market` | Необязательны; рынок `unknown` | Исходное имя компании и рынок |
| `include_title` | Необязательное regex | Фильтр названия без учёта регистра после сохранения снимка |
| `max_pages` | 3; диапазон 1–20 | Ограничение страниц Lever/HH |
| `request_gap_seconds` | 4; диапазон 4–30 | Пауза между запросами к хосту |
| `interval_seconds` | 3600; минимум 4 | Время следующей допустимой попытки |
| `allowed_hosts` | Необязательный список | Разрешённые хосты; хост endpoint добавляется |
| `user_agent` | Идентификатор read-only клиента | HTTP User-Agent |
| `proxy_allowed` | False | Явное разрешение прокси для источника |
| `proxy_env` | Необязательно | Имя переменной с прокси; требует разрешения |

Клиент не следует редиректам и не наследует обычные proxy-переменные, использует timeout 25 секунд и проверяет размер ответа 5 МБ после загрузки. Повторы и доступ описаны в [источниках](SOURCES.md). Это не полная сетевая изоляция.

## Факты и изменение политики

Версионируйте доказательства через `facts import PATH`; `facts.json` не является шаблоном CV. Нужны уникальные ID, источники и классификация `verified`, `self_reported` или `conflicting`. Профили содержат ровно `product` и `technical-leadership`.

Локальный источник — существующий файл относительно импортируемого JSON. Строка «интервью с кандидатом» не заменяет путь. HTTP(S)-источники сохраняются как URL; импорт сам по себе не проверяет их утверждения. Подробнее — [модель данных](DATA_MODEL.md).

После изменения фактов, компании, требований или политики уровня повторите оценку. Старый пакет сохраняет исходный контекст; изменение документа требует новой версии и ревью.

## Что настраивается отдельно

CLI не устанавливает планировщик, не управляет календарём, не ограничивает денежный бюджет моделей, не вызывает LLM API, не шифрует backup и не отправляет отклики. Доступность моделей, разрешение внешних сервисов, внешнее резервирование, хранение копий и ручные маршруты источников требуют отдельной настройки. Произвольное новое поле JSON не добавляет такую функцию.
